# Mueblería Hermanos Jota

Sitio web e-commerce para Mueblería Hermanos Jota, desarrollado como proyecto final de los Sprints 1 y 2.

El proyecto simula la experiencia de compra de una mueblería utilizando HTML, CSS y JavaScript del lado del cliente.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## Funcionalidades

- Página de inicio con productos destacados.
- Catálogo completo de productos.
- Detalle individual de cada producto.
- Productos cargados dinámicamente mediante JavaScript.
- Simulación de carga asíncrona.
- Buscador de productos.
- Carrito de compra simulado con contador.
- Formulario de contacto con validación.
- Diseño responsive para dispositivos móviles y escritorio.
- Navegación entre las diferentes páginas del sitio.
